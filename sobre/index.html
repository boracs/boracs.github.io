Desarrollador web en Donostia

Desarrollo la aplicación web de tu empresa: reservas, cobros, tienda y el resto de la operativa, en una sola pieza. Ahora mismo estoy construyendo la de San Sebastián Surf School: clases, alquiler de tablas, taquillas, tienda y subastas, todo desde una misma web.

Trabajo con comercios, autónomos, emprendedores y pequeñas empresas de Donostia y alrededores. Llevo tu idea a la web —o arreglo la que ya tienes— por un precio que un negocio pequeño puede pagar.

Qué aporto

  • Seriedad

    Lo acordado es lo entregado. Te explico en claro qué estás pagando y por qué, sin letra pequeña.

  • Disponibilidad

    Respondo y nos vemos en Donostia. Trato directo: hablas con quien hace el trabajo, no con un intermediario.

  • Compromiso

    No doy la web por lista hasta que funciona de verdad: pedidos que entran, pagos que se cobran, clientes que reservan.

Con qué trabajo

Grado Superior en Desarrollo de Aplicaciones Web y curso de creación de páginas web. A grandes rasgos, con esto trabajo:

Web

  • HTML, CSS y JavaScript
  • PHP
  • React
  • Bootstrap y Tailwind
  • Inertia.js y Vite

Programación

  • Java · orientación a objetos (herencia, interfaces, polimorfismo…)
  • C / C++ · punteros, memoria y herencia múltiple
  • Ficheros y algoritmos de búsqueda y ordenación

Datos y bases de datos

  • XML, JSON y AJAX
  • localStorage, cookies y tokens
  • MySQL · modelo entidad-relación (1:1, 1:n, n:n con tablas pivote)
  • Eloquent ORM (Laravel): migraciones, relaciones y casts · seguridad con $fillable y consultas preparadas

Backend y pagos

  • Laravel 12: rutas, middleware, colas y notificaciones
  • Stripe Checkout y webhooks
  • TicketBAI (facturación fiscal)
  • Autenticación: Breeze, Sanctum, verificación de email y login con Google
  • Tests con Pest

CMS

  • WordPress · nivel amplio
  • Joomla

Sistemas y versiones

  • Linux y Windows · sobre todo comandos de Linux
  • Git y GitHub
  • Visual Studio Code
  • Docker

IA en el flujo de trabajo

  • Google Gemini integrado en la app: chatbot y resúmenes del parte diario
